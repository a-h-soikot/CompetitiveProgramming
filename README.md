# Algorithm & Data Structure Snippets (Sublime Text)
This repository contains Sublime Text snippets for commonly used algorithms, data structures, and other repetitive codes written in C++.
They help quickly insert boilerplate code during problem-solving or competitive programming so that one can focus on solving problems.
Snippets are kept simple, clean, and easy to customize.

## ⚙️ How to Use
1. Open **Sublime Text**.
2. Go to **Preferences → Browse Packages…**
3. Enter the **User** directory.
4. Copy/Download the **.sublime-snippet** files from `Sublime Text - Snippets and Builds` folder of this repository and put them into the **/Pacakages/User** folder.
5. In the editor, type the snippet’s trigger and press **Tab** or **Enter** to expand.

### 📂 Other Files
- The `OtherFiles` folder contains pre-created C++ files, as well as `input.txt` and `output.txt` files, so one don’t have to create them manually (if they haven't already). This saves time when practicing or preparing for contests.
- Running `init_cp_files.py` will reset all the C++ and input/output files at once, so one don’t have to reset them manually before a contest.
